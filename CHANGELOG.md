# Change Log

All notable changes to the "diablo-theme" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

- Add Dotenv highlighting to all themes for VS Code's built-in grammar and
  mikestead.dotenv, including keys, values, interpolation and comments.
- Separate variable/parameter colors from functions and methods in every theme,
  including explicit callable highlighting in Necromancer Light.
- Give variables and parameters an accent color distinct from property names in
  all four themes, with matching TextMate and semantic highlighting.
- Added Paladin Dark (Ivory & Midnight) and Paladin Light, including Workbench,
  chat, Git/Diff, TextMate and semantic token colors.
- Initial release
