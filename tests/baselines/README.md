# Frozen baseline: palette architecture migration, step 1

These JSON files are verbatim copies of the generated Necromancer Dark and
Necromancer Light themes at the start of migration. They are independent expected
data: no palette imports, placeholders or computed colors.

`npm run build` writes only `themes/`. No build, check or test command updates
these snapshots. During architecture migration, keep them unchanged and fix the
implementation when a comparison fails. Do not copy a changed build over them
to make tests pass. A future intentional visual change needs a separately reviewed
baseline update; there is deliberately no snapshot-update command.

Run `npm run build:check` for a read-only comparison of source output, generated
JSON and these frozen files. It checks every Workbench/Git color, semantic token,
TextMate rule, rule/selector order, fontStyle and all other theme properties, then
requires exact generated bytes. Missing or malformed files fail the check.

`npm test` builds both themes and runs the existing tests, baseline guard tests
and the same baseline comparison. Guard tests mutate copies in memory to prove
that changes are rejected; they never modify the snapshots.
